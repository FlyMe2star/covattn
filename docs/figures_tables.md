# Figures and tables: what each one shows (facts for writing captions)

Generated by `scripts/make_figures.py` and `scripts/make_tables.py` from result files only; layout check with
`tools/paper_preview.py` (llncs class, text width 347 pt = 12.2 cm; every table fits, every figure is 4.8 in wide,
all lettering >= 6 pt). This file lists definitions and conventions, not results.

## Conventions used everywhere

- g = <e_hat, e> / ||e||^2 (effect gain; 1 = exact magnitude, < 1 = attenuated). Reported as the median over pairs.
- r = Pearson correlation of e_hat and e over the horizon (shape). NRMSE = ||e_hat - e|| / ||e|| (what-if error).
- err. ratio = factual absolute error of the median forecast divided by zero-shot's, per series; median reported.
- Pairs whose true effect is below 5% of the context std are excluded (effect mask), as in all experiments.
- **Bold in tables** = best training-free method in that column (g: closest to 1; r: highest; NRMSE / MASE / WQL /
  ratios: lowest). Fine-tuned models (full FT, LoRA) and ARX are reference rows and are never bolded; for the
  error ratio (relative to zero-shot) the zero-shot row is not a candidate. Ties after rounding are all bold.
- Method colours in figures: zero-shot orange, R1 blue, R2 green, dither dark grey, fine-tuned / ARX grey.
